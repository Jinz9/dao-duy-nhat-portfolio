# Đào Duy Nhật - Personal Portfolio 🌐

Trang web giới thiệu cá nhân và các dự án công nghệ, nghiên cứu nổi bật.

---

## 🚀 Tính năng & Công nghệ sử dụng

- **Frontend:** HTML5, CSS3, JavaScript (Vite)
- **Thiết kế:** Phong cách tối giản, hiện đại
- **Build di động:** Tích hợp Capacitor hỗ trợ đóng gói trực tiếp thành ứng dụng Android (APK)
- **CI/CD:** Tự động build web và xuất file APK qua GitHub Actions

---
